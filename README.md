# Desk2Dine 🍽️
### Faculty Canteen Order Management System

Desk2Dine is a Java Spring Boot-based web application designed to simplify food ordering, delivery tracking, billing, and payment management within a college campus.

## Project Overview

The project aims to replace manual canteen order management with an organized digital system. It supports faculty members in placing food orders and tracking their progress, while providing canteen staff with tools to manage orders, deliveries, bills, and payments.

## Key Features

- **Faculty Management:** Faculty members can access the system and manage their food orders.
- **Menu Management:** Manage available canteen items and their details.
- **Order Placement:** Place orders by selecting items, quantities, and delivery locations.
- **Order Tracking:** Monitor orders throughout their lifecycle.
- **Delivery Management:** Track deliveries and acknowledge receipt of orders.
- **Billing and Payments:** Generate bills, record payments, and complete orders.
- **Order Records:** Maintain organized records of orders and their statuses.

## Order Workflow

Placed → Delivered → Received → Billed → Paid → Completed

## Technology Stack

- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS
- **Build Tool:** Apache Maven
- **Development IDE:** Eclipse
- **Database:** Local database with Java database connectivity
- **Version Control:** Git and GitHub

## Project Structure

- `src/main/java` — Java application code
- `controller` — Handles application requests
- `service` — Contains business logic
- `repository` — Manages database operations
- `entity` — Defines application data models
- `src/main/resources/templates` — HTML templates
- `application.properties` — Application configuration
- `pom.xml` — Maven dependencies and build configuration

## Running the Project

1. Clone the repository:
   `git clone https://github.com/deepanshisinghal29/Desk2Dine.git`
2. Open the project in Eclipse as a Maven project.
3. Ensure Java and the required Maven dependencies are available.
4. Configure the local database as required by the application.
5. Run `Desk2dineApplication.java`.
6. Open `http://localhost:2901` in your browser.
